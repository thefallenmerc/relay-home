# Relay Home artwork

These 16 original transparent PNG sprite pairs were generated with the built-in image_gen tool on 2026-11-12. They are bundled app assets, not downloaded at runtime. No reference screenshot pixels were extracted. The supplied UI screenshots informed the cream, charcoal, and emerald art direction.

Each image has two equal square frames: **ON on the left, OFF on the right**. Every sprite is preserved as generated with its alpha channel. ApplianceArt crops the appropriate half at paint time, decodes to 768 pixels wide, and shares a bounded cache across tiles. This keeps the two states aligned and avoids storing duplicate decoded images per relay. Imported user artwork uses the same image in both states; the control and state label communicate ON/OFF.

All 14 appliance presets have a distinct generated pair. The board and router are additional setup illustrations. Device presets lighting_board and appliance_board intentionally share board.png. No app logo is included here; the app mark is drawn as native vector artwork elsewhere in the project.

All outputs were visually inspected for matching ON/OFF halves, complete silhouettes, absence of text, and recognizable subjects. The production assets are included in `assets/art/`.
